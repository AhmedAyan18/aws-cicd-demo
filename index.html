GitHub Actions CI/CD Demo

Automated CI/CD deployment using GitHub Actions, Amazon EC2, SSH, SCP, and Apache HTTP Server.

⚡ Continuous Integration & Deployment Flow
📂
1. Source
Code is stored in a GitHub repository. A push to the main branch automatically triggers the GitHub Actions workflow.
⚙️
2. GitHub Actions
GitHub Actions checks out the latest code and runs automated tests to verify the application.
🚀
3. Deploy
GitHub Actions securely transfers the website files to the Amazon EC2 server using SSH and SCP.
🌐
4. Apache Server
Apache HTTP Server serves the deployed website from the EC2 instance on port 80.
GitHub Actions Workflow
on: push: branches: - main jobs: build-and-deploy: runs-on: ubuntu-latest steps: - Checkout code - Test application - Copy files to EC2 - Deploy to EC2
EC2 Deployment
Server: Amazon EC2 Operating System: Amazon Linux 2023 Web Server: Apache HTTP Server Apache Service: httpd Web Directory: /var/www/html Deployment: SSH + SCP
