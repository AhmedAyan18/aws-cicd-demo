⚡ Continuous Integration & Deployment Flow
🚀
1. Source
Code pushed to repository triggers the AWS CodePipeline.
🛠️
2. Build
AWS CodeBuild executes buildspec.yml to package artifacts.
📦
3. Deploy
AWS CodeDeploy uses appspec.yml and lifecycle scripts to update EC2.
buildspec.yml
version: 0.2 phases: build: commands: - echo Packaging artifacts... artifacts: files: - '**/*'
appspec.yml
version: 0.0 os: linux files: - source: / destination: /var/www/html hooks: ApplicationStart: - location: scripts/start_server.sh
